# 一隅跨设备同步

1. 创建自己的 Supabase 项目。在项目的 SQL Editor 运行同目录中的 `yinu-sync.sql`，初始化同步表和接口。
2. 在 Supabase Authentication 中启用邮箱登录。若启用了邮件确认，注册后在邮箱验证，然后回到一隅登录。也可以由项目管理员事先创建账号。
3. 在手机打开「设置 → 跨设备同步」，填项目 HTTPS 地址、Publishable 公钥（旧项目可用 anon 公钥）以及邮箱和密码。在另一台设备重复操作，使用同一个项目和账号。
4. 在第一台设备新建一条记录，等待下一次同步或点「立即同步」。然后在另一台设备点「立即同步」，检查收到的记录。可继续验证编辑、收藏、离线删除和重新联网后的同步。

登录前一隅继续使用本机数据。首次登录会上传已有记录。同步包含文字、收藏及分组、删除、引用及关联、附件信息。附件文件本体仍可用「数据与存储」里的 ZIP 备份迁移。置顶和提醒按设备保留。退出登录只停止这台设备的同步，本机记录继续可用。本机记录绑定第一次成功登录的项目和账号，避免后续登录其他账号时意外上传已有记录。

应用运行时约每 30 秒合并一次，进入前台也会检查。退到后台后由 Android 按有网络的周期任务调度，时间取决于系统。设备离线时的修改留在本机，联网后重试。两台设备同时改了同一条记录时，采用较新的记录版本。请让两台设备使用自动日期和时间。

手机客户端只需要公钥。同步表禁止未登录访问，登录后只能读取本账号的记录，写入接口从会话识别当前账号。密码只在登录时使用，会话凭据用 Android Keystore 加密保存。打开同步后，记录正文会存入你选择的项目。
